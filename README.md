# Sasori 100 Packages

This monorepo includes `sasori-mini-utils` and 100 source packages with callable APIs and tests. The 100 packages are arranged in 5 contexts (blog, docs, store, community, ops) across 20 operations. Each imports and uses a function from the core library.

Run `npm install` and `npm test` with Node 18+.

**Important:** These are first-party demonstration packages, not third-party adoption or 100 separate GitHub dependent repositories. None are published to npm. Review and maintain packages before any public release.
